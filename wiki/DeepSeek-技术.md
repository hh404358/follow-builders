# DeepSeek 技术

> **摘要**：DeepSeek 是中国 AI 开源生态的核心力量，从 V2 到 V4 持续推动 MoE 架构和长上下文推理的边界。其多模态技术报告揭示了"七千倍极致压缩"和"视觉原语思考"的创新路径，LCA 实现 90% KV 缓存缩减 + 2.5 倍推理提速，V4 更是首次使用华为昇腾芯片完成大规模训练。本主题整合 4 篇原始材料。

## 背景：DeepSeek 的定位

DeepSeek 的核心策略：**用极低算力实现接近顶级的模型能力**。这一策略不是妥协，而是工程极致：
- V2：首创 DeepSeekMoE 稀疏激活架构
- V3：多 token 预测 + 辅助损失无关负载均衡
- V4：1M 上下文 + 华为昇腾芯片 + 完全开源

## 关键技术分析

### 1. 多模态技术：七千倍极致压缩

DeepSeek 多模态技术报告的核心创新：
- **视觉原语思考**：不将视觉信息翻译为文本描述，而是让模型直接在视觉原语空间中推理
- **指代鸿沟破解**：解决多模态模型在"图中哪个区域"类指代表达上的长期缺陷
- **七千倍压缩**：视觉编码器将图像压缩为极少量 token，同时保留关键语义信息
- **算力效率**：消耗算力仅为其他顶级多模态模型的几十分之一

→ 与 [[Claude Code 与 Harness Engineering]] 的关联：DeepSeek 的极致压缩理念与 Harness 的 Token 优化目标一致——用更少资源做更多事。

### 2. LCA：长文本加速神器

ACL 2026 论文，核心贡献：
- **90% KV 缓存缩减**：通过注意力模式分析，识别并剪枝冗余的 KV 对
- **2.5 倍推理提速**：在不损失质量的前提下大幅加速长文本推理
- **对 Agent 的意义**：→ 详见 [[AI Agent 架构]]，长上下文是 Agent 可靠性的基础，LCA 使百万级上下文在实际推理中变得可行

### 3. V4：开源新里程碑

- **V4-Pro**：1.6T 总参数 / 49B 活跃参数，接近 GPT-5.5 水平
- **V4-Flash**：284B 总参数 / 13B 活跃参数，专注高速推理
- **1M 上下文窗口**：配合 LCA 技术实现高效长文本推理
- **华为昇腾芯片**：首次验证国产 AI 芯片在大规模训练中的可行性

### 4. 被删论文事件

DeepSeek 曾连夜删除一篇论文，引发社区广泛关注。该论文可能涉及：
- 未成熟的训练方法披露
- 潜在的安全风险
- 商业策略考量

→ 这一事件本身反映了 AI 开源社区在"开放"与"安全"之间的张力。
