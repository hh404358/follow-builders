# 知识库构建

> **摘要**：知识库是 AI 时代的"第二大脑"。从 IMA 知识库使用指南到 Skill 分类学，本主题整合 3 篇原始材料，构建个人知识管理的完整方法论。

## 背景

CLAUDE.md 核心工作流："研究→创新→实现→沉淀"。知识库是"沉淀"环节的核心载体——没有系统化的知识沉淀，研究成果无法复用，创新无法积累。

## 核心方法论

### 1. IMA 知识库使用指南

IMA 知识库的核心架构：
- **raw/**：原始材料收集（文章、论文、笔记）
- **wiki/**：结构化知识（主题文章、跨主题链接）
- **output/**：输出成果（Prompt、技巧总结）
- **learn/**：学习方法论
- **写论文/**：学术写作工具

→ 这正是本维基的构建基础：raw → wiki 的编译流程。

### 2. Skill 分类学

"Skill 其实就是分类学"——将知识按领域、粒度、依赖关系组织为可组合的技能树：
- **领域分类**：AI 工程 / 多模态 / 持续学习 / Agent
- **粒度分层**：概念级 → 方法级 → 工具级
- **依赖关系**：基础技能 → 组合技能 → 高级技能

→ 这与 [[AI Agent 架构]] 中 OpenClaw 的技能注册机制和 [[Claude Code 与 Harness Engineering]] 的工具层设计一致。

### 3. 大模型 AI 知识库保姆级教程

构建 AI 知识库的关键步骤：
1. **收集**：多源聚合（RSS、微信文章、论文、笔记）
2. **分类**：按主题和粒度组织
3. **索引**：Embedding + 向量检索 → 详见 [[Embedding 模型选型]]
4. **链接**：建立跨主题关联（[[双链]]格式）
5. **迭代**：定期编译 raw → wiki

## 知识库架构设计

```
知识库/
├── raw/           # 原始材料（只增不改）
│   ├── 文章/
│   ├── 论文/
│   └── 笔记/
├── wiki/          # 结构化知识（编译产物）
│   ├── INDEX.md   # 主题索引
│   └── *.md       # 主题文章
├── output/        # 输出成果
│   ├── Prompt/
│   └── 技巧/
└── learn/         # 学习方法论
```
